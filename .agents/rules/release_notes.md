# Releases.md Maintenance Rule

## Mandatory Workflow Requirement
Whenever changes are made to the codebase (features, enhancements, bug fixes, UI adjustments, performance optimizations, or build system changes) and a Pull Request is prepared, `Releases.md` is updated and committed as part of the PR.

The rule in full -- where the entry goes, its sections and what it names -- is in `CONTRIBUTING.md` under *Release notes*. Read it before writing the entry.
