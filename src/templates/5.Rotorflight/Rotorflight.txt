Starting point for a Rotorflight helicopter.

Brings the pieces no script can set later: the SW1 function switch prepared as ARM (red while armed), switch warnings, the throttle warning off, the blackbox, backup, pot and trim channels, and the RFSuite dashboard as the main view.

Then asks for your switches with the radio's own pickers - arming (SW1 preselected), the hold position that locks the motor, governor, profiles, rescue - and lays the channels out like the reference models. If you arm on a function switch other than SW1, its name and colours have to be moved by hand; no script can do that.

Connect the flight controller afterwards and run the setup assistant (SYS > Tools > RFSuite > Configuration > Wizards); it reads this layout back and sets the flight controller to match.
