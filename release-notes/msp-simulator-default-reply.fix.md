- **In the EdgeTX simulator a message without a simulator reply is no longer dropped in silence (`tasks/msp/queue.lua`)**: a write that carries no `simulatorResponse` is answered with an empty reply, as the flight controller answers a write, and a read without one ends through its error handler with the reason `no_simulator_response`; the warning line that names the missing reply stays. A Save on the two Servos pages no longer leaves the loading overlay standing in the simulator, Copy Profile and Select Profile can save again, and a save through the save pipeline completes there instead of ending after its 30 s backstop. With a flight controller attached nothing changes (#859).
