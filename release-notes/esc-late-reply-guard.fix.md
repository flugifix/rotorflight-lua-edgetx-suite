- **The ten ESC Configurator pages ignore the answer to a save once the page has been left (`app/pages/setup/esc_motors/esc_tools/escmfg`, `docs/reference/saving.md`)**: the write still goes to the ESC, but its answer no longer runs against the closed page. Before, it stopped with an error in the log, and on AM32, BLHeli_S and Bluejay it re-armed the post-save reset, so the next visit ran that reset in place of its connection sequence; the same now holds for the answer to that reset when the page is left while it is out (#574).
