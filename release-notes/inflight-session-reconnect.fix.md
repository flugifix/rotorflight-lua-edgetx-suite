- **In-flight tuning: the tuning session belongs to the flight controller it was read from (`widgets/dashboard/inflight/prime.lua`, `docs/dashboard/inflight-tuning.md`)**:
  - A second flight controller connected to the same model kept the first one's undo: the automatic backup was skipped, the comparison after the flight was measured against the first board, and *Restore* copied the new board's spare profile over the one it flies. The session now ends when a different board identifies itself, and that board is read again in full. A reconnect to the same board ends nothing, so the backup taken before the flight survives a battery change, a fade on the ground or a link lost in the air.
