- **A sensor name that resolves to nothing is now remembered as a miss (`lib/sensors.lua`)**:
  - `Sensors.resolveName` memoises its answer per name, but its write could not store a miss: `(resolved == nil) and false or resolved` yields `nil` when `resolved` is `nil`, so every read of a name in neither `Sensors.map` nor `Sensors.aliases` ran the whole name match again. The dashboard reads three such names on every telemetry pass (`temp_mcu`, `temp_esc`, `watts`) and two more for the ESC status (`Esc#`, `EscF`). A miss is now stored as `false`, as the comment above the memo already said; measured on desktop Lua 5.3, a repeated miss costs 13 instructions instead of 34 (a hit costs 12). The answer for every name is unchanged (#767).
