- **A sensor name that resolves to nothing is now remembered as a miss (`lib/sensors.lua`)**:
  - `Sensors.resolveName` memoises its answer per name, but its write could not store a miss: `(resolved == nil) and false or resolved` yields `nil` when `resolved` is `nil`, so every read of a name in neither `Sensors.map` nor `Sensors.aliases` ran the whole name match again. The dashboard reads two such names on its telemetry path (`watts`, `EscF`). A miss is now stored as `false`, as the comment above the memo already said, and a repeated miss costs 13 instructions instead of 34 (a hit costs 12). The answer for every name is unchanged (#767).
