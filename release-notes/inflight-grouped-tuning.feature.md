- **In-flight tuning is grouped by axis and subsystem, tunes every reachable profile, and offers only what the flight controller carries (`widgets/dashboard/inflight`, `widgets/dashboard/runtime.lua`, `lib/model_preferences.lua`, `widgets/dashboard/themes/{deck,grid,urban}/layout.lua`, `app/manifest.lua`, `app/pages/init.lua`, `bin/accounting`, `tasks/events/telemetry_bg/adjustments.lua`, `app/pages/settings/dashboard/inflight/page.lua`, `audio/<lang>/inflight/`, `bin/sound-generator/json/`, `docs/dashboard/inflight-tuning.md`, `docs/pages/settings/dashboard/inflight.md`, `docs/audio/events.md`)**:
  - The functions are grouped by axis and subsystem (Cyclic, Roll, Pitch, Yaw, Governor, Rates, Filter, Cross Coupling, Rescue and Level, Acc Trim, Other) and carry the Rotorflight Configurator's own names in each language, on screen and in speech; each function and group is spoken from one recording of exactly that name. Tapping the group title opens a picker of every group inside the tuning screen (touch or encoder; RTN closes it); the arrows, and PAGE in value mode, walk the functions of the group, PAGE in browse changes the group; the ends do not wrap and play a tone, independent of the adjustment announcement preference.
  - The set is always derived on the ground read from the board's own adjustment slots, so a slot holding another function can no longer be stepped under a different name; nothing is offered before that read. *Set up suggested functions* on the ground overlay writes the suggested layout, now with each parameter's full range instead of 10 to 200 (a rescue hover collective of 600 fell to 200 on the first press); the *Set layout* setting is gone. A value outside its slot's minimum and maximum refuses its step.
  - Every PID and rate profile the profile switch can reach is read on the ground and its start values are stored per model on the SD card, bound to the flight controller they were read from. Tuning continues across profile changes in the air; an unread profile refuses steps. *Restore* writes back per profile or all at once, keeps untracked fields, saves once and reads back; every read and restore returns to the original profile pair and waits while armed or disconnected. The post-flight comparison is grouped by profile and group.
  - A new ground surface: three status lines (model, flight-controller slots, session), **Choose parameters** as the primary action (a ticked group list; *Apply* for this session, *Save default* also as the model's flight list), *Read again*, *Reset start values* (asks first) and *Restore all* set apart. Read and restore show one progress screen with a step count.
  - In the air there is no Close and RTN only leaves value mode; every flight starts at the first function of the first group. Value mode shows the value on the left and the plus/minus step targets stacked on the right. The encoder walks a list that is rebuilt before it runs out, so it can no longer reach the touch controls and change the selected function.
  - New spoken states under the adjustment announcement setting: tuning paused on an unread or unknown profile, resumed, selected. Paused/resumed cues play only in flight; profile numbers are announced once, with the general PID/rate event taking ownership when enabled.
  - Trims are off by default for everyone; pilots who tuned with the trims turn them on again in the settings.
  - Always-active adjustment slots are checked in every bank, so an overlapping pulse refuses the affected step direction. Ground reads accept PID gains and rescue altitude P/I/D gains up to the firmware limit of 1000 and a governor head speed up to 50000; an invalid value names its function and value in the refusal.
  - Tuning is released only while its fullscreen surface is open in the foreground, reached from the dashboard quick menu. The interlock switch setting and zone tuning surface are removed; stored switch values are ignored. Ground X/RTN returns to the quick menu without ending the session. Firmware fullscreen exit, background, link loss and feature disable clear both variables immediately. Closing in the air pauses; reopening in the same flight continues at the same group and parameter.
  - Ground profile plans are built one target per pass, keeping full-profile restores within the existing widget instruction budget alongside fullscreen input and telemetry.
  - Reconnects reread the complete FC setup on the ground and resume the union of current and stored profiles, adding fresh start values only for newly reachable profiles.
  - The ground surface warns when Adjustment Announcements are off and offers an explicit button to enable and save the existing radio-wide preference, with a warning if saving fails.
  - Ground status uses a filled panel with dim labels and verdict colours, a taller primary action, uniform secondary action cells and an announcement warning or controls footer on all three supported display sizes; 800x480 uses standard status and secondary text with a larger primary caption when it fits.
  - A lost link pauses output immediately while retaining the tuning visit, showing PAUSED and No FC link while tuning. Link recovery resumes the same group, entry and session automatically once arm telemetry is known; the existing flight-controller identity check still refuses steps until the board is identified, except that a link returning in the air with a fresh armed reading continues the same flight before landing. A different controller ends a suspended read/return job and permits its own ground read. The post-flight list survives a fullscreen pause, widget interruption or link loss and is recomputed after a fresh read, and the ground model-status line follows repaired setup faults. Session timestamps display as `YYYY-MM-DD HH:MM` while retaining SD compatibility.
  - Suggested FC functions are set up from the tuning overlay on the ground, with per-model step choices, an overwrite plan before confirmation, write/read-back progress, an idle model save and a fresh ground read. The old Setup > Controls page and the radio settings' flight-list section are removed; Choose parameters on the ground is the only flight-list editor. A model whose board carries tuning slots is now tunable whenever the radio's master switch is on; the per-model switch and set mode are ignored.
