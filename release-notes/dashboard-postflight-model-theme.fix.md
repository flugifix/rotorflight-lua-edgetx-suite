- **After a flight, unplugging the battery no longer switches the post-flight screen from the model's own theme to the radio's (`widgets/dashboard/runtime.lua`, `docs/pages/settings/dashboard/theme.md`, `docs/dashboard/themes.md`, `docs/developer/dashboard-themes.md`)**:
  - The link going takes the model's preferences with it, and a preferences check that fell on the very pass the link went reloaded them without the board's id, so the screen resolved the radio's theme. The widget now keeps the path the model's own theme resolved for the post-flight screen and uses it on the post-flight screens while no model preferences are present, until the next flight controller connects (#747).
