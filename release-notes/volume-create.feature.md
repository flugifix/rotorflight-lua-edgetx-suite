- **The Volume page can create the model's master-volume chain (`app/pages/settings/audio/volume/`, `i18n/en.lua`, `i18n/de.lua`, `docs/pages/settings/audio/volume.md`)**:
  - In *Master volume*, while the check does not find the whole chain, a *Create* row offers a *Preview*: EdgeTX's confirm dialog lists each link to be written as EdgeTX shows it and the links already there as *present*, with *No* focused. On *Yes* the missing links are written into the last free input, logical switch and special function; an empty input or logical switch that another input line, logical switch, special function, flight mode or timer still names does not count as free (mixes and the radio's *Global Functions* cannot be read). Correct links already in the model are used as they are.
  - A faulty link is never changed: *Create* is then unavailable and the check names the fault. It is also unavailable until *Mode* *Master volume* and the global variable shown are saved (the line under it says so; when a faulty link or a missing slot holds it back too, that reason stands there instead), with no free slot, with all 64 input lines used, while the model is armed or its arming state is not known, and without the confirm dialog.
  - The model is read again at *Yes*, and nothing is written unless it still asks for exactly what the preview listed. Each write is read back; the check then runs again and its answer is what the page reports. A write that does not take is named with what was already created, and *Create* offers the rest. Nothing is ever removed from the model; the docs say how to take the chain out by hand.
  - The check warns when a flight mode that has a switch has a value of its own for the global variable instead of FM0's: in that flight mode the volume does not follow the suite. EdgeTX's Lua cannot set a flight mode back to FM0's value, so *Create* changes no flight mode and the docs say how to do it in EdgeTX.
  - No new setting; in *Off*, which is the default, the page is unchanged.
