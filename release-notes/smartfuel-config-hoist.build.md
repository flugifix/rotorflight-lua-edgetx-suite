- **SmartFuel no longer rebuilds its configuration and reset signature on every wake (`tasks/events/telemetry_bg/smart.lua`)**:
  - `Smart.wakeup` computes once a second in every Lua state that runs the event runtime (the dashboard and service widgets, the tool). Each of those wakes built a new configuration table through three fresh closures and a parsed API version, and joined seven `tostring` results into a string to decide whether to restart the estimate, although both only change when a setting or the battery configuration does. The helpers are now file-level functions, the configuration is rebuilt only when one of its input values differs from the last wake (compared by value, so a page writing into the session's tables in place is still seen), and the restart test compares the seven values field by field. Measured on desktop Lua 5.3, a computing wake with unchanged inputs allocates nothing instead of 945 bytes, and costs 608 instructions instead of 697 (firmware source) or 847 instead of 927 (local voltage source). The configuration and every restart decision are unchanged, except that a cell count reported as `6.0` where it was `6` no longer restarts the estimate (#768).
