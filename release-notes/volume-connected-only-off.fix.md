- **A new Master volume setup starts with Connected only off (`app/pages/settings/audio/volume/`, `i18n/en.lua`, `i18n/de.lua`, `docs/pages/settings/audio/volume.md`)**:
  - Picking *Master volume* on the Volume page while *Connected only* has never been set now starts it from the connected-only switch the callout level had before the page offered one mode -- off in a fresh install's settings file -- instead of on. Saved that way, the *Normal Level* is written from the moment the dashboard or the tool starts. Turning it on keeps bench and menu work at the pot's volume, as before.
  - Settings files are read as before: a file that already stores *Connected only* keeps it, and a file written before the setting existed that opens in *Master volume* still reads it as on, also when *Master volume* is picked again on the page. Nothing changes for the announcements or the global-variable writes of an existing settings file; what changes is the starting value of a *Master volume* setup made on the page.
