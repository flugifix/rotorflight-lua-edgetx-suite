- **Urban, Grid and Deck build their render key without a temporary list (`widgets/dashboard/themes/urban/layout.lua`, `widgets/dashboard/themes/grid/layout.lua`, `widgets/dashboard/themes/deck/layout.lua`)**:
  - `L.renderKey` runs every 0.5 s in the host's state pass and joined its terms with `table.concat({ ... }, "|")`, although its comment said no table was allocated. The key is now one `..` expression with the same terms, order and separator, so the list is no longer built: measured on desktop Lua 5.3 with unchanged inputs, a call allocates 1 byte instead of 201 (Urban, Grid) and 217 (Deck), and 200 or 216 bytes less with a long model-image path, where the key itself is a new string on every call. The key is byte-identical for every input, and the comment now says what the function still allocates (#765).
