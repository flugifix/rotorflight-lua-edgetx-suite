- **Urban, Grid and Deck build their render key without a temporary list (`widgets/dashboard/themes/urban/layout.lua`, `widgets/dashboard/themes/grid/layout.lua`, `widgets/dashboard/themes/deck/layout.lua`)**:
  - `L.renderKey` runs every 0.5 s in the host's state pass and joined its terms with `table.concat({ ... }, "|")`, although its comment said no table was allocated. The key is now one `..` expression with the same terms, order and separator, so the list is no longer built: a call allocates 200 bytes less in Urban and Grid and 216 bytes less in Deck. Measured on desktop Lua 5.3 with unchanged inputs and the suite logo's path in the key (a model picture's path is always in it), Urban allocates 119 bytes per call instead of 319; what is left is the key string itself. The key is byte-identical for every input, and the comment now says what the function still allocates.
