- **Choosing other curves, another flight or a new chart size no longer keeps the previous plot's buckets alive while the new ones are read (`app/pages/logs/graph.lua`)**:
  - `G.applyColumns`, `G.selectSession` and `G.setGeometry` empty the window cache and start a new read, but `S.rbSrc`, the bucket set the last re-bucketing read from, stayed in place until that read ended, so the old buckets could not be collected while the new ones filled beside them. `beginExtract` now drops it whenever it starts a read from the file. Measured on desktop Lua 5.3 (64-bit) over a 5 000-row log: right after each of the three, the previous plot's set is no longer held -- 66.5 kB when it was drawn at 476 px, 132.0 kB at 796 px; every point and every curve range is identical (#770).
