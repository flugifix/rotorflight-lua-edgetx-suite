- **ESC telemetry wiring can be detected on the Telemetry page (`app/pages/setup/esc_motors/telemetry/page.lua`, `app/pages/setup/esc_motors/telemetry/help.lua`, `tasks/msp/api/esc_sensor_trial.lua`, `i18n/en.lua`, `i18n/de.lua`, `docs/pages/setup/esc_motors/telemetry.md`)**:
  - *Setup* > *ESC & Motors* > *Telemetry* gains *Detect wiring*: on MSP API 12.10 and a flight controller that answers the wiring trial command, the flight controller tries the *Half Duplex* and *Pin Swap* combinations for the saved telemetry protocol. The button is not shown otherwise.
  - While detection runs the fields, Save and Reload are locked; *Cancel* stops it and restores the previous wiring. A detected wiring fills *Half Duplex* and *Pin Swap* as unsaved changes for the normal Save and reboot. A failed, cancelled or interrupted detection asks for a Reload before saving (#816).
