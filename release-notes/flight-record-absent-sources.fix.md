- **Absent flight statistics (`tasks/events/telemetry/flight_record.lua`, `widgets/dashboard/objects/common.lua`)**: A sensor that never answers, such as a missing ESC temperature or altitude sensor or one not found yet at the first sample, leaves its statistic empty instead of recording 0 in the flight record, flight log and post-flight tiles. While armed, a statistic box or gauge shows no value for a statistic the flight has not taken yet instead of the previous flight's value; Urban, Grid and Deck's own views are unchanged.
