  - For #729, each theme's Keys page binds only the keys left on Theme on Settings > Dashboard > Keys, and marks the ones held there (global); as the radio comes those are PAGE >, PAGE <, SYS and TELE, so a theme's own PAGE binding takes effect only after the pilot sets PAGE to Theme on Settings > Dashboard > Keys.
