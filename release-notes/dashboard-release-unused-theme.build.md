- **The dashboard releases a theme no widget uses any more (`widgets/dashboard/runtime.lua`, `docs/developer/dashboard-themes.md`)**:
  - A theme's shared modules (Urban's, Grid's and Deck's `layout.lua`, `common.lua` and view kit, a declarative theme's `common.lua`) stayed in memory for the life of the widget's Lua state once the theme had been shown. When the dashboard moves to a theme in another folder, every theme folder that no dashboard widget shows or has chosen for a phase is now released: its module cache entries and its `__rfsuiteTheme...Module` globals. Measured on desktop Lua 5.3 after Urban, Grid and Deck were shown in turn, about 400 KiB less is resident with Deck on screen. The next time a released theme is shown it is read from the card again, as on its first load; `default` is never released. A phase change within one theme and a settings save release nothing (#766).
