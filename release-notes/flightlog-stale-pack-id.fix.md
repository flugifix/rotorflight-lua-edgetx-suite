- **A flight is no longer logged against a pack the battery registry no longer holds (`tasks/events/ondisarm/tasks/flight_log.lua`, `lib/flight_log.lua`)**: the pack chosen for a model is looked up in `batteries.cfg` at the disarm. Where the pack was deleted or given a new id -- in the file itself, or on the Flight Log page while another model was connected -- the flight's line is written with an empty battery column, no cycle is counted, the log names the id at warning level, and the model's stale choice is cleared. A registry the card does not read whole is not judged (#855).
