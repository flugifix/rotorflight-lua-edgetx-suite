- **After an install the dashboard compiles the suite before it connects (`lib/precompile.lua`, `widgets/dashboard/runtime.lua`, `widgets/service/runtime.lua`)**: the compile pass ran only when the configuration tool was started from *System*, so a pilot who used the dashboard alone paid for every file on the first opening of each page, and the tool opened from the dashboard skipped the pass entirely. When the installed build has not been compiled yet, the dashboard and the service widget now run the pass first, the splash reads *Preparing suite* with its progress, and the connection to the flight controller starts once it has finished; the tool opened from the dashboard meanwhile shows the same pass instead of starting another. A build that is already compiled costs two small file reads and connects as before.
