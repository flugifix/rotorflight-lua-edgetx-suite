- **After an install the dashboard compiles the suite before it connects, and asks for a restart of the radio (`lib/precompile.lua`, `widgets/dashboard/runtime.lua`, `widgets/service/runtime.lua`)**: the compile pass ran only when the configuration tool was started from *System*, so a pilot who used the dashboard alone paid for every file on the first opening of each page, and the tool opened from the dashboard skipped the pass entirely. When the installed build has not been compiled yet, the dashboard and the service widget now run the pass first, with *Preparing suite* and its progress on the splash; once it has finished, the splash asks for a restart of the radio and the dashboard does not connect until then, because the code loaded before the pass is still the previous build's. The tool shows the same request once after its own pass, and the tool opened from the dashboard meanwhile shows the same pass instead of starting another. A build that is already compiled costs two small file reads and connects as before.
